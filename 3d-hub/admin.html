📖 Google Apps Script 后端部署说明（3步完成）

  1. 打开你绑定 Google Sheets 的 Apps Script 编辑器，将最新的 3d-hub/Code.gs 代码完整覆盖粘贴并保存（Ctrl+S）。
  2. 在编辑器上方函数下拉框中选择 authorizeTelegramPermission 并点击 「运行 (Run)」，按提示允许外部网络请求权限；然后点击右上角 「部署 (Deploy)」→「管理部署」→ 编辑 → 版本选「新版本」。
  3. 在 Telegram 对你的机器人发送 /start（确保已启动对话），再填入上方 Token 与 Chat ID 保存并测试！系统已内置浏览器直连 Telegram 双通道兜底，即使 GAS 未授权外部请求也可在浏览器端直接发出测试通知。
