# 🎪 小小义卖会 · 一年级钱币交易游戏 (`bazaar-game`)

纯前端静态网页应用（HTML5 / CSS3 / Vanilla JS），无需任何后端服务器，可直接通过 GitHub / Cloudflare Pages 托管，或双击 `index.html` 在课室电子白板与平板离线运行。

## ✨ 核心功能

- **马来西亚令吉与仙分级解锁**：
  - ⭐ **1星**：`RM1`、`RM5`、`RM10`（20 样整数价格商品）
  - ⭐⭐ **2星**：加入 `10仙`、`20仙`、`50仙`、`RM20`（累计 40 样商品）
  - ⭐⭐⭐ **3星**：加入 `5仙`、`RM50`（累计 60 样商品）
  - ⭐⭐⭐⭐ **4星**：加入 `RM100`（累计 80 样商品）
- **四大教学关卡**：认识与数钱、小顾客买东西、小老板找零钱（往上数教学支架）、义卖会大冒险（小老板 / 小顾客双角色扮家家酒）。
- **老师自定义菜单**：点击「👩‍🏫 老师设置」即可自定义摊位名、学校名与商品价钱，修改自动保存在本机浏览器 `localStorage`。
